# SEU 生存指南 2.0

> 完整离线版 · 抓取自极客文档：<https://geekdaxue.co/read/chengqing-ddfhl@ckpcv7/cr8aqk>

这是一份由东南大学（SEU）校友自发编写的「**大学生存指南 2.0**」完整离线版，涵盖学业、升学、求职、创业、转专业、生活、校友经验等共 **65** 篇文章。

## 📖 阅读方式

仓库已按**原文章结构**拆分为独立 Markdown 文件。点击下方目录中的任意篇目即可阅读；所有图片使用相对路径保存在 `assets/uploads_projects/` 下，**在 GitHub 上直接打开即可看到原文插图**。

- 推荐在 GitHub 网页上直接浏览（图片即时显示）
- 也可 clone 到本地用 Typora / Obsidian / VS Code 阅读
